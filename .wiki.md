# Project Summary
Paper Explainer is a Repro Suite product that turns public arXiv papers into short, narrated videos in English and Chinese. Visitors can generate and share videos, browse finished examples, and order a reviewed Studio video. Each video is checked for quotes and numbers against the paper text before recording.

The single-page site also explains the workflow, presents pricing, and collects general or video-specific feedback. It uses a shared Repro Suite design system with light and dark themes. The former demo list, in-browser draft player, and full-video request flow have been removed.

# Project Module Description
- **Single-page experience (`frontend/src/pages/Index.tsx`)** — Composes the hero, video creation, examples, process, pricing, feedback, and footer sections in order.
- **Site shell (`frontend/src/components/Shell.tsx`)** — Provides responsive sidebar navigation, active-section highlighting, mobile drawer, language switch, and theme toggle.
- **Video creation (`frontend/src/components/sections/MakeSection.tsx`, `frontend/src/lib/explainer.ts`)** — Submits arXiv IDs or links to the video service, polls job status, shows progress, and displays finished videos with language selection, downloads, sharing, and video feedback. Visitors are limited to three new videos per day by the service.
- **Examples and media (`frontend/src/components/sections/ExamplesSection.tsx`, `frontend/src/components/media.tsx`)** — Loads finished videos and real usage statistics, provides language selection and sharing/download controls, and opens videos in a lightbox.
- **Product information (`frontend/src/components/sections/Hero.tsx`, `HowSection.tsx`, `PricingSection.tsx`)** — Introduces the service, explains its checking and recording workflow, and presents free and Studio options.
- **Feedback (`frontend/src/components/sections/FeedbackSection.tsx`, `frontend/src/components/VideoFeedback.tsx`, `frontend/src/lib/feedback.ts`)** — Collects general ratings and comments or feedback attached to a specific video.
- **Studio orders** — Accepts email, paper, language, and notes for paid Studio video requests; orders are saved by the backend.
- **Backend persistence and APIs** — FastAPI routes, models, services, and migration support feedback and Studio orders while retaining existing tables.
- **Preferences and styling (`frontend/src/lib/prefs.tsx`, `frontend/src/index.css`)** — Shares English/Chinese language preferences and persists the theme under `repro.theme2`.

# Technology Stack
- **Frontend:** React, TypeScript, Vite, Tailwind CSS, and shared UI components.
- **Backend:** Python, FastAPI, SQLAlchemy, and Alembic.
- **Video generation:** Explainer-render service for job submission, status polling, recent videos, and MP4 assets.
- **Persistence:** Relational database for existing records, feedback, and Studio orders.
- **Preferences:** Browser local storage for theme and visitor identity; English and Chinese interface.
- **Quality checks:** ESLint, Playwright configuration, and frontend build checks.

# Usage
1. Install backend dependencies:
   ```bash
   cd app/backend
   pip install -r requirements.txt
   ```
2. Install frontend dependencies:
   ```bash
   cd app/frontend
   npm install
   ```
3. Configure the database and backend application settings. Keep secrets out of frontend code.
4. Apply database migrations:
   ```bash
   cd app/backend
   alembic upgrade head
   ```
5. Start the app with the repository helper:
   ```bash
   ./app/start_app_v2.sh
   ```
   Alternatively, run the backend with `uvicorn main:app --reload` from `app/backend` and the frontend with `npm run dev` from `app/frontend`.
6. Build the frontend:
   ```bash
   cd app/frontend
   npm run build
   ```
   Refer to `frontend/package.json` for additional scripts.
