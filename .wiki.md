# Project Summary
Paper Explainer helps researchers promote papers with short, cinematic video previews. Visitors can watch previews, request a full video without logging in, or create an AI-generated preview for an arXiv paper. New previews are checked against available paper text, played in the existing 16:9 player, and saved for display on the home page. Full-video requests and made-preview records are stored in the database. Payments are not part of this version.

The site includes three demo papers, English and Chinese narration and subtitles, and light and dark themes. Made previews have no recorded narration; the player uses the browser’s built-in voice. AI-generated scripts can still contain mistakes and should be checked before sharing.

# Project Module Description
- **Home (`frontend/src/pages/Index.tsx`)** — Presents demo papers, an “Explain your own paper” input for an arXiv ID or link, and the six latest saved previews.
- **Watch (`frontend/src/pages/Watch.tsx`)** — Plays a demo paper and provides language switching, replay controls, and a full-video request form.
- **Make (`frontend/src/pages/Make.tsx`)** — Guides visitors through paper retrieval, script generation, evidence checks, and playback. Supports English and Chinese, displays progress, and offers a retry on rate limits.
- **Preview generation (`frontend/src/lib/makePreview.ts`)** — Retrieves paper details and text, generates a script, verifies scene evidence and numbers against the paper text, and sends the script to the player. If full text is unavailable, it uses the abstract and indicates this to the visitor.
- **Player and review (`frontend/src/lib/usePlayerEnded.ts`)** — Supports player completion behavior. The Make page uses the shared player in waiting mode, with a language switch and Replay control, followed by a scene-by-scene evidence review and draft disclaimer.
- **Request panel (`frontend/src/components/RequestPanel.tsx`)** — Shared full-video request form, including on the Make page with the paper’s arXiv ID prefilled.
- **Latest previews API and persistence** — Backend routes, model, service, migration, and data model support saving made-preview metadata and retrieving recent previews. A failed save does not prevent playback.
- **Authentication and preferences** — Frontend auth context and theme/language preferences; backend auth and user modules. Paper previews and requests are available to anonymous visitors.
- **Supporting APIs** — Health, settings, storage, and AI Hub routes and services.
- **Paper explainer assets** — Prebuilt player, demo scripts, narration, index data, and scene prompt under `frontend/public/explainer/`.
- **Blog and prerendering** — Blog routes, article components, and prerender utilities are included in the frontend.

# Technology Stack
- **Frontend:** React, TypeScript, Vite, Tailwind CSS, and a shared UI component library.
- **Backend:** Python, FastAPI, SQLAlchemy, and Alembic.
- **Data:** Relational database configured through the backend; full-video requests and made-preview metadata are persisted there.
- **Paper and script services:** Browser-side requests to paper retrieval and AI script-generation services; no service keys are stored in the app.
- **Media:** Static paper scripts and MP3 narration served from frontend public assets. Made previews use browser speech synthesis.
- **Testing and quality:** ESLint, Playwright configuration, and plugin tests.

# Usage
1. Install backend dependencies:
   ```bash
   cd app/backend
   pip install -r requirements.txt
   ```
2. Install frontend dependencies:
   ```bash
   cd app/frontend
   npm install
   ```
3. Configure required database and application settings for the environment. Do not put secrets or keys in frontend code.
4. Apply database migrations from `app/backend`:
   ```bash
   alembic upgrade head
   ```
5. Start the app using the repository helper:
   ```bash
   ./app/start_app_v2.sh
   ```
   Alternatively, start the backend with `uvicorn main:app --reload` from `app/backend` and the frontend with `npm run dev` from `app/frontend`.
6. Check frontend scripts in `app/frontend/package.json` for build and lint commands. Build the frontend with:
   ```bash
   npm run build
   ```
