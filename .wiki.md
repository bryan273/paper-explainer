# Project Summary
Paper Explainer is a site for turning research papers into short, cinematic video previews. Authors can share a 20-second preview to promote a paper; viewers can request the full video by submitting their email, arXiv ID, and an optional note. Requests are saved to the database without requiring login. Payments are not part of this version.

The site includes three demo papers, English and Chinese narration and subtitles, a dark video player framed by a calm blue-and-neutral interface, and light and dark themes. Each scene is described as tied to a quote from its paper. The supplied player is served as-is in a 16:9 iframe.

# Project Module Description
- **Home (`frontend/src/pages/Index.tsx`)** — Presents the 20-second preview concept and demo cards populated from `/explainer/index.json`.
- **Watch (`frontend/src/pages/Watch.tsx`)** — Embeds the player with the selected paper and language. After the preview, viewers can submit a full-video request and receive a request number. Includes language switching and replay controls.
- **Authentication and preferences** — Frontend auth context and theme/language preferences; backend auth and user modules. Request submission is available to anonymous visitors.
- **Request API and persistence** — Backend routes, models, schemas, and services handle full-video requests and store them in the database.
- **Supporting APIs** — Health, settings, storage, and AI Hub routes and services.
- **Paper explainer assets** — Prebuilt player, paper scripts, audio narration, and index data under `frontend/public/explainer/`.
- **Blog and prerendering** — Blog routes, article components, and prerender utilities are included in the frontend.

# Technology Stack
- **Frontend:** React, TypeScript, Vite, Tailwind CSS, and a shared UI component library.
- **Backend:** Python, FastAPI, SQLAlchemy, and Alembic.
- **Data:** Relational database configured through the backend; full-video requests are persisted there.
- **Media:** Static paper scripts and MP3 narration served from the frontend public assets.
- **Testing and quality:** ESLint, Playwright configuration, and plugin tests.

# Usage
1. Install backend dependencies:
   ```bash
   cd app/backend
   pip install -r requirements.txt
   ```
2. Install frontend dependencies:
   ```bash
   cd app/frontend
   npm install
   ```
3. Configure required database and application settings for the environment. Do not place secrets or keys in frontend code.
4. Apply database migrations from `app/backend`:
   ```bash
   alembic upgrade head
   ```
5. Start the app using the repository helper:
   ```bash
   ./app/start_app_v2.sh
   ```
   Alternatively, start the backend with `uvicorn main:app --reload` from `app/backend` and the frontend with `npm run dev` from `app/frontend`.
6. Check frontend scripts in `app/frontend/package.json` for build and lint commands; the production build can be run with:
   ```bash
   npm run build
   ```
